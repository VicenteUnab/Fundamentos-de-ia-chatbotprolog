# Respuestas del chatbot LLM (gemini-3.8-flash)

**3. ¿Qué plantas son fáciles de cuidar?**

Las plantas fáciles de cuidar son sansevieria, zamioculca, suculenta. Estas cumplen con ser resistentes y requerir un nivel de riego bajo.

**12. ¿La calathea es apta para principiantes?**

No, la calathea no es apta para principiantes, ya que no figura como una planta resistente en la base de conocimiento.

**13. ¿Qué necesita la calathea?**

La calathea necesita luz media, riego alto y humedad alta. Además, está registrada como segura para mascotas.

**14. ¿Qué necesita el potus?**

El potus necesita luz media, riego medio y humedad media. Además, es una planta resistente y adecuada para principiantes.

**15. ¿La cinta es segura para mascotas?**

Sí, la cinta está registrada como una planta segura para mascotas. Por lo tanto, es adecuada para ubicarse en hogares con mascotas.

**16. ¿El potus es apto para poca luz?**

No, el potus no es apto para poca luz, ya que requiere luz media.

**17. ¿La suculenta necesita luz alta?**

Sí, la suculenta necesita luz alta.

**18. ¿Qué planta puedo usar si olvido regarla seguido?**

Las plantas que necesitan poco riego son sansevieria, zamioculca, suculenta. Estas opciones son ideales si sueles olvidar regarlas seguido.

**19. ¿Conoces la zamioculca?**

Sí, conozco la zamioculca. Es una planta resistente que requiere baja luz, poco riego y baja humedad, por lo que es de fácil cuidado y apta para principiantes. Cabe señalar que no está registrada como segura para mascotas.

**20. ¿Qué cuidados tiene el ficus?**

El ficus requiere luz alta, riego medio y humedad media. No está registrado en la base como resistente ni como seguro para mascotas.
